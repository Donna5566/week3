# Campus Equipment Checkout Database

This project creates a database to manage campus equipment borrowing.

The database tracks students, equipment, categories, and checkout records.

## Project Files

- requirements.md: Business rules and requirements 
- er_diagram.md: Conceptual ER diagram
- logical_model.md: Relational database design
- schema.sql: MySQL table definitions
- queries.sql: SQL queries
- diagrams/: ER diagram image
- data.sql: Sample database records
